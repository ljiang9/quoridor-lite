# quoridor-lite

9×9 迷宫棋（Quoridor）极简实现：走子 + 放墙挡路，谁先到达对方底线谁胜。纯 Python 标准库，无第三方依赖。

## 玩法

- 甲从第 8 行出发，目标是第 0 行；乙从第 0 行出发，目标是第 8 行。
- 每回合二选一：**走子**（上下左右走一格）或**放墙**（每人 10 面墙）。
- 墙长 2 格，横/竖放置，不能重叠交叉；**放墙不能把任何一方的路完全堵死**（BFS 校验）。
- 跳子规则：与对方棋子相邻时可直线跳过；直线落点被墙/棋盘边挡住时，可落到对方棋子远端的两个斜格（官方规则）。

## 用法

```bash
python -m quoridor_lite                  # 交互模式（需要终端）
python -m quoridor_lite --auto           # AI 对 AI 自动演示 10 局
python -m quoridor_lite --auto --games 20 --seed 7 --verbose
```

交互命令：`m 行 列` 走子，`w h/v 行 列` 放墙，`q` 退出。

## AI

1 步贪心：评估 `(对手最短路 − 自己最短路)`，走子沿最短路、放墙专挑让对手绕远的 24 个候选。跳进墙围死胡同是合法但愚蠢的走法，评估时按路长 999 处理（AI 会自动避开）。

## 已知局限（诚实版）

- AI 只是 1 步贪心，不做深层搜索；放墙候选每步只采样 24 面，熟悉定式的人类通常能赢
- 文本棋盘，无图形界面/动画/存档/悔棋
- 跳子斜跳落点只校验在棋盘内（官方规则本就如此）
- Python 3.10+，纯标准库
